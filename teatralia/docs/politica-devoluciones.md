# Política de devoluciones de Teatralia

Versión 3 · aprobada por Operaciones y Finanzas · aplica a todos los promotores

Esta política es la **fuente de verdad** para atención al cliente y para el equipo de desarrollo.
Si el sistema no hace lo que dice este documento, el error está en el sistema.

## 1. Evento cancelado

- Se devuelve **todo**: el precio de las entradas y los gastos de gestión.
- La devolución es automática: el comprador no tiene que pedirla.

## 2. Evento aplazado

- Las entradas siguen siendo válidas para la nueva fecha.
- Si el comprador no puede ir, puede pedir la devolución hasta 48 h antes de la nueva fecha.
- Se devuelve el **precio de las entradas**. Los **gastos de gestión no se devuelven**: el servicio de venta ya se prestó.

## 3. Petición del cliente (evento que se celebra)

- Solo hasta **48 h antes** del comienzo del evento.
- Se puede devolver el pedido entero o solo algunas entradas.
- Se devuelve el precio de las entradas con una **penalización del 10 %**. Los gastos de gestión no se devuelven.
- La penalización se calcula sobre el **importe total** de las entradas devueltas y se **redondea al céntimo**
  (por ejemplo, dos entradas de 18,25 €: 36,50 € − 10 % = 32,85 €).

## 4. Doble cobro

- Si la pasarela cobró dos veces el mismo pedido, se devuelve el **cargo duplicado completo**.

## 5. Invitaciones

- Las entradas de precio 0 no generan devolución.

## 6. Registro

- Cada devolución queda registrada con su motivo, las entradas afectadas y el importe.
- Una entrada devuelta deja de ser válida y su butaca vuelve a la venta.
